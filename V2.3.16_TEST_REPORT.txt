v2.3.16 浏览器发送读取图层兼容修复
依据：用户 v2.3.15 截图显示“读取图层失败”，定位到图层树捕获阶段；尚无完整错误码，不能确定是哪一个 DOM 属性报错。
变更：使用 Action Manager numberOfLayers/layerID/visible/layerSection 获取图层树，取消源文档逐层 DOM id/visible 读取。识别组开始/结束标记，背景图层索引从 0 开始；普通文档索引从 1 开始。复制后校验树与临时文档结构一致，避免误导出。
通过：JSX VM 语法及 runtime Node 语法检查；模拟组/子层、未选中兄弟层隔离、源 layers getter 抛错时仍可成功导出、临时文档关闭和原文档恢复。
未进行真实 Photoshop 上传测试。
人工验收：重启 Photoshop 后，使用此前失败的单图片文档重试；另验证背景层、嵌套组、多选、空图层选择整画布及选区优先。检查图片尺寸不缩放、源文档历史和图层不变。
