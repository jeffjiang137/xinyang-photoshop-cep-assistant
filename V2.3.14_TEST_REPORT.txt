v2.3.14 浏览器发送范围与 Web PNG

规则：有像素选区时导出选区外接矩形内可见画面；否则有选中图层时导出选中图层；图层选择列表为空时导出完整画布，不做透明边界裁剪。
尺寸：不缩放、不改变分辨率；画布模式保持画布宽高，选区和图层模式保持各自范围的原像素尺寸。
格式：Save for Web PNG-24，透明、非交错、不含 ICC profile。无损压缩，不进行 PNG-8 量化。不能保证复杂大图压缩到固定体积。浏览器可能重新编码剪贴板图片，实际附件体积由浏览器决定。

通过：runtime.js、diagnostics.js 的 Node 语法检查；browser-export.jsx 的 VM 语法检查。
通过：模拟宿主验证空 targetLayersIDs 列表不会回退活动图层；canvas/layers/selection 三种范围；选区优先；整画布不裁剪；Web PNG 参数；源文档不变和临时文档关闭。未调用尺寸缩放。
未实测：真实 Photoshop（版本未确认）与浏览器附件上传。

人工验收：
1. 在 3000×2000 PSD 中通过“选择 > 取消选择图层”取消所有图层选择，发送；确认附件为 3000×2000，保留透明画布边缘。
2. 选中图层发送，核对原图层像素范围；多选、组、文字、锁定层、智能对象和剪贴蒙版按 V2.3.13 报告验收。
3. 保留 500×600 像素选区并取消图层选择，发送；确认选区优先且附件为 500×600。
4. 对比导出 PNG 的像素尺寸与源范围，无缩放；检查透明区域、渐变与文字。浏览器重新编码时另外检查附件体积。
5. 检查源 PSD 历史、选区、可见性不变，Ctrl+Z 撤销此前用户操作。
6. 超大画布若超过 Photoshop Save for Web 能力，应提示错误而非静默缩放；原文档不受影响。
