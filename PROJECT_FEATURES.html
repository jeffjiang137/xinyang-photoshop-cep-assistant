01 / LONG IMAGE & EXPORT

长图拼接与切片导出

把多张商品素材整理成长详情页，也能从已有画布按参考线或画板输出图片。

批量导入拼图

拖放或批量选择 JPG、PNG、WEBP、PSD、PSB、TIF、BMP 等素材，按设定宽度排成连续长图。

智能切片

按切片线与画布边界导出详情页分段；无切片线时支持整画布导出。保留原始画布作为编辑来源。

原生画板导出

多画板时调用 Photoshop 自带 ArtboardExport 核心处理可见画板与 JPG 输出；当前版本修复原生入口上下文变量缺失。

导出路径示意

输入多图素材 / PSD / PSB
排布目标宽度、顺序、间距
切片参考线、切片线或画板
输出分段图片 / 画板 JPG
复核文件名、数量、尺寸

图示为概念流程。画板与大画布输出请使用测试 PSD 实际核对像素、坐标与文件数量。

02 / LAYOUT & DOCUMENT

版式搭建与文档辅助

从空白画布到可编辑布局，减少重复创建框架、尺寸和参考线的手工步骤。

规则框架

使用行列表达式建立矩形、圆形或方形布局，适用于商品陈列、规格组合与素材占位。

电商尺寸预设

快速建立常用画布，也可输入自定义宽高与分辨率，衔接主图、详情页、海报等设计任务。

参考线与安全区

辅助建立版面分区、边距和内容安全区域；GuideGuide 风格工具用于更细致的网格布局。

间距管理

围绕选中图层整理水平/垂直留白，让多块素材的边缘和间距更一致。

03 / OCR & IMAGE CLEANUP

图片文字识别与内容清理

将栅格图片中的文字转成可编辑对象，并提供按需配置的擦除服务连接方式。

OCR 图片转文字

识别图片中的文字区域，并生成 Photoshop 文字图层，方便校对、替换与重新排版。

擦除原文字

可连接本机 LaMa / IOPaint 服务清理原文字区域；也可按当前功能调用 Photoshop 内容感知等处理。

翻译与文案处理

文字面板可配置在线翻译凭据；服务凭据由用户自行提供，禁止提交到公开仓库。

04 / TYPOGRAPHY

文字排版与批量处理

减少逐层点选和重复套样式，让电商页面中的标题、参数和卖点层级更易整理。

字体与字符属性

调整字体、字重、颜色与样式；支持常见字符/段落排版参数及光学字距相关操作。

对齐与分布

对文字图层进行水平/垂直对齐和间距整理，降低多个标题与说明文字的重复操作。

拆分与层级

支持文字拆分、分组及自动排版辅助；效果取决于选中对象类型及 Photoshop 文档状态。

05 / EVERYDAY TOOLS

图层、素材与输出工具箱

把高频小操作收进共同入口：导入、布局、变换、修复、瘦身、批量输出与浏览器协作。

导入与置入

单张或批量导入图片、嵌入一个或多个素材、按布局辅助填充画布。

定位与变换

图层对齐/分布、画布居中、智能吸附、翻转、缩放与自定义变换。

清理与查找

图层/文件瘦身、查找相似图层、替换元素或颜色、模糊修复及图层排列辅助。

文字与形状细节

批量文本属性、文本对齐、矩形批量参数，以及填充/描边颜色交换等辅助操作。

文件导出

常用格式导出与批量导出；具体尺寸、格式及压缩质量由当前导出面板选择。

发送到浏览器

将选区、所选图层或整幅画布导为原像素尺寸 PNG，复制到 Windows 剪贴板并尝试粘贴至浏览器焦点。

浏览器发送会覆盖系统剪贴板，目标网页需要支持图片粘贴且输入框已聚焦。该功能不会自动点击发送，也不会确认网页是否完成附件上传；请发送前检查目标窗口和内容。

07 / PRACTICAL WORKFLOW

一个详情页素材整理流程

按素材整理、画布搭建、文案处理到分段交付逐步推进；每一步都留在 Photoshop 可编辑文档中。

01 · 整理素材批量导入商品图、参数图和品牌素材。
02 · 搭建版面创建画布、网格、安全区与内容分组。
03 · 处理图片文案OCR 识别或手动校正文案，按需清理旧文字。
04 · 排版与对齐整理字体层级、对齐、间距和视觉结构。
05 · 导出复核按切片线/画板导出，核对图片和源文档。
08 / INSTALL & COMPATIBILITY

安装、兼容与验证说明

适用于 Adobe Photoshop CEP 面板环境，项目使用浏览器侧 JavaScript 与 ExtendScript 宿主模块。

安装

下载 GitHub ZIP，将扩展目录放入 `%APPDATA%\Adobe\CEP\extensions\com.jeffjiang.ecommerce-design-assistant-cep`，按 Adobe CEP 调试扩展要求设置后重启 Photoshop。

按需配置

拼图、排版和多数图层工具可本机使用；OCR、翻译、擦字及 Bridge 等服务能力需按功能配置本机服务或个人凭据。

当前版本与验证

v2.3.20。自动/模拟回归报告覆盖原生画板保存分支适配；真实 Photoshop 像素导出仍需人工验收，不把模拟结果等同于完整实机通过。

隐私与安全

仓库不应包含服务密钥、令牌、用户数据库或业务 PSD。Bridge 令牌不可公开；浏览器发送前请确认焦点窗口。

架构入口

index.html 是面板入口；浏览器侧模块位于 js/modules/；Photoshop 宿主模块由 jsx/module-loader.jsx 加载。

获取帮助
